# Algorithms

Собственные реализации классических структур данных и алгоритмов на Java
без использования готовых коллекций. Каждый пакет — отдельная тема со своим
`Main` для демонстрации.

## Содержание

| Пакет | Что реализовано |
|-------|-----------------|
| `arrays` | Динамический массив `MyArrayList`: пузырьковая сортировка, сортировка выбором и вставками с замером времени; `MySortedArrayList` с сортированной вставкой и бинарным поиском |
| `stacks` | Стек, очередь, дек и приоритетная очередь на массиве; проверка расстановки скобок, переворот введённой строки через стек |
| `lists` | Односвязный и двусвязный списки с итератором; стек и очередь на связном списке |
| `recursion` | Рекурсия: факториал, Фибоначчи, треугольные числа, возведение в степень (в т.ч. отрицательную); задача о рюкзаке (жадный и рекурсивный перебор) |
| `trees` | Двоичное дерево поиска `MyTreeMap` с проверкой сбалансированности; эксперимент — доля сбалансированных среди 10 000 случайных деревьев |
| `graphs` | Граф на списках смежности, поиск пути в глубину и в ширину |

## Сборка и запуск

Требуется JDK 11+.

```bash
javac -encoding UTF-8 -d out $(find src -name '*.java')
java -cp out graphs.Main
```
